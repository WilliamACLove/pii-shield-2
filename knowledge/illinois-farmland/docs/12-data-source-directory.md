# Annotated Data Source Directory

A curated, grouped directory of every data source, statute, and reference used to build this knowledge base — what each one provides, how often it updates, and what to use it for.

**Built/verified:** 2026-07-12

## How to use this directory

- Entries are grouped by source type, strongest evidentiary standing first (per `../SOURCING.md`'s primary-source hierarchy).
- **Archival status**: this knowledge base was built in a network-restricted environment (see `../SOURCING.md`, "Build-environment disclosure"). Every URL below marked "not yet byte-verified" comes from `../sources/MANIFEST.md` and was identified via hosted web search, not opened and checksummed directly — treat figures drawn from these as well-sourced but not document-confirmed until a follow-up session with open egress completes the archive pass. Entries not in the manifest (mostly Group 6 corroborating/press material) were never queued for archival and carry no such note.
- Items ISPFMRA (Illinois Society of Professional Farm Managers and Rural Appraisers) publishes are **intentionally manifest-only**: this is a paid, member-organization survey product, and per this knowledge base's copyright rule the report body itself is never archived or reproduced — only cited.
- **Annual refresh calendar** (repeated from `../SOURCING.md` so this directory is self-contained as a bookmarking reference):

  | Release | Publisher | Typical timing |
  |---|---|---|
  | Land Values Summary | USDA NASS | early August |
  | Cash Rents (state & county) | USDA NASS | September (county detail follows) |
  | Illinois Land Values and Lease Trends | ISPFMRA | late March |
  | Certified farmland EAV values | Illinois Dept. of Revenue | certified in spring for following assessment year |
  | AgLetter (7th District land values) | Federal Reserve Bank of Chicago | quarterly (Feb/May/Aug/Nov) |
  | Crop budgets, operator & land returns | U. of I. farmdoc | summer/fall updates |

- **Curation note**: this is a directory, not a dump. Of roughly 120 candidate URLs surfaced during research, about 70 survive into the entries below. Dropped material included: generic/undated homepage links that duplicate a more specific entry already listed; commercial vendors' PDF mirrors of a public-university document (e.g., a farm-software company's re-hosted copy of Bulletin 811); duplicate press write-ups of the same NASS/ISPFMRA release (kept the earliest or most substantive write-up only); statute mirrors on non-government sites (findlaw, etc.) where the ilga.gov original is already listed; and a few low-confidence blog posts already flagged as unverifiable in the research notes. See the end of each group for what was specifically dropped and why.
